# Star Savior Wiki

《Star Savior》非官方中文攻略站，基于 Next.js 构建，部署于 GitHub Pages。

## 简介

本站为游戏《Star Savior》（별의 구원자 / Star Savior）的玩家中文攻略站，收录以下内容：

- **旅行攻略** — 困难模式事件选择与流程攻略
- **攻略列表** — 开荒路线、角色培养与流派思路
- **支援卡** — 支援卡信息与图鉴
- **参考** — 游戏相关资料与数据

## 技术栈

- **框架**: [Next.js](https://nextjs.org/)
- **样式**: Tailwind CSS
- **部署**: GitHub Pages
- **构建输出**: 静态导出 (`output: 'export'`)

## 部署说明

`gh-pages` 分支为 GitHub Pages 自动部署分支。该分支由构建流程自动生成，请勿直接修改此分支下的文件。
